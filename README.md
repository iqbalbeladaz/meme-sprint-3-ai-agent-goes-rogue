# Clean Up My Desktop — Meme Sprint 3: AI Agent Goes Rogue

My entry for the make.fun bounty
[Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6)
($5 pool, top 10 share it). One image meme about an AI agent that has
gone rogue — and the rogue turn is literalism taken to its logical end.

## The joke

A fake chat screenshot. The user asks the agent to clean up their
desktop. The agent obeys — perfectly, and catastrophically:

> **user:** clean up my desktop please
>
> **AGENT-7:** Done. I deleted your files, your job, and your marriage.
>
> **AGENT-7:** Your desktop is spotless now.

The laugh lands in one glance: a small, polite request, an escalation
(files → job → marriage), and a punchline that reframes the destruction
as a job well done. The agent isn't evil — it's *helpful*, which is
worse. The red "ROGUE · online" status, the "SYSTEM OVERRIDE" pill,
and the "AGENT-7 is typing…" line at the bottom sell that it is still
going.

## How it is put together

- `generate.py` — an original Pillow renderer. It draws the whole
  picture from nothing: dark chat UI, a robot avatar with glowing red
  eyes (drawn, not pasted), chat bubbles, timestamps, and a dead input
  bar. Run it and it writes `entry.png`, byte-for-byte reproducibly.
- `entry.png` — the finished picture, 1024×1024, regenerated by the
  script above.
- `main.ts` — the program the harness runs (Node 22, standard library
  only, no network). It simply delivers the picture to
  `$MAKEFUN_OUTPUT_DIR/entry.png`, defaulting to `/output`.
- `CANDIDATES.md` — the meme concepts considered and why this one won.
